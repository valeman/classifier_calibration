# A note on archive.zip
The file directory in the zip file is:
```
.archive/
├─ results.txt           # Nested dict with measurements (arch -> dataset -> [runs])
├─ datasets_md.txt       # Per-dataset metadata collected by DatasetSuite
├─ experiment_md.txt     # Experiment metadata (seed, machine specs)
├─ assets/               # Plots and images generated by analyse_results.py
└─ results_*             # If merging outputs across jobs/runs
```

The sub-directories "results_*" contain the raw output from running main.py on select models and datasets.  <br>
results.txt etc in the root directory merge these outputs. The assets are generated based on the merged output. <br>

Below recites what each sub-directory contains: <br>
2: rf, ext, mlp, ebm, remlp, lgbm <br>
2_1: tpfn <br>
2_2: A rerun of tpfn + platt <br>
2_3: A merged version of 2_1 and 2_2 <br>
3: svm, lr, ttra, knn, cb, xgb <br>
3_1 A rerun of ttra <br>
3_2: ticl <br>
4: tabm, nca  <br>
4_1 : A rerun of ticl + platt <br>
4_2: avg, lda, nb, gbc, hgb <br>
4_3: A rerun of avg <br>



The assets directory contain many premade plots derived from the data in the .txt files. <br>
- .\abs\rank\archs : Ranks all architectures by different measures. 
- .\abs\rank\archs : Ranks all base models/learners by different measures. 
- .\cost : Plots training and inference costs. 
- .\cost\util : Plots resource utilization (% of maximum) 
- .\delta\rel\dist : Plots displaying the relative effect of each calibration method. Each subdir collects the results of a model. The subdir "phcms" aggregates across all models. 
- .\delta\marg\rank : Plots ranking each calibration method per measure and model by marginal effect. 
- .\delta\marg\dist : Plots displaying the marginal effect of each calibration method. Each subdir collects the results of a model. The subdir "phcms" aggregates across all models.
