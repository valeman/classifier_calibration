# A note on archive.zip
The sub-directories "results_*" contain the raw output from running main.py on select models and datasets.  <br>
results.txt etc in the root directory merge these outputs. The assets are generated based on the merged output. <br>

Below recites what each sub-directory contains: <br>
2: rf, ext, mlp, ebm, remlp, lgbm <br>
2_1: tpfn <br>
2_2: A rerun of tpfn + platt <br>
2_3: A merged version of 2_1 and 2_2 <br>
3: svm, lr, ttra, knn, cb, xgb <br>
3_1 A rerun of ttra <br>
3_2: ticl <br>
4: tabm, nca  <br>
4_1 : A rerun of ticl + platt <br>
4_2: avg, lda, nb, gbc, hgb <br>
4_3: A rerun of avg <br>
